# 02 三段式检验

每一个候选请求权，都依次回答三个问题。

主位结论可以停在不成立的那一段，但要写明停在哪一段、因为什么。**以下情形，后续各段仍要完成**，至少列出可能的抗辩结构：
- 前一段的结论是"待证"或"有争议"；
- 存在备位请求，或律师需要知道"即使前一段成立，后面还有哪些障碍"。

## 第一段：请求权是否已经产生

检验请求权基础规范的**全部构成要件**是否齐备。

- 把规范拆成要件清单（要件来自数据层返回的条文与通行的要件理解，交律师确认）。
- 逐项涵摄，方法见 `03-subsumption-and-burden.md`。
- 同时检查**权利未发生的抗辩**：对方主张某一要件不存在，或主张存在阻止权利发生的事由。

常见的权利未发生抗辩：

| 类型 | 例 |
| --- | --- |
| 合同未成立 | 要约承诺不一致、缺少必要条款 |
| 合同无效 | 违反强制性规定或公序良俗、恶意串通、虚假意思表示 |
| 合同未生效 | 附生效条件未成就、须经批准未批准 |
| 主体问题 | 无民事行为能力、无代理权且未追认、主体不适格 |
| 要件事实不存在 | 未交付、未提供服务、无损害、无因果关系 |
| 免责事由 | 不可抗力；合同约定的顺延或免责条款（条款能否约束对方另查，如格式条款）；可能只免除部分责任，例如扣减部分迟延天数 |
| 条款不约束对方 | 格式条款未订入合同或无效，致据以请求的约定条款不能适用 |

## 第二段：请求权是否未消灭

请求权产生后，可能因法定事由消灭。检查**权利消灭的抗辩**：

| 类型 | 例 |
| --- | --- |
| 清偿 | 已付款、已交付、第三人代为履行 |
| 抵销 | 法定抵销、约定抵销 |
| 提存 | 依法提存 |
| 免除 | 债权人放弃债权 |
| 混同 | 债权债务归于一人 |
| 解除 | 合同解除后，履行请求消灭，转为返还、赔偿请求 |
| 撤销 | 可撤销的法律行为被撤销，自始失去效力（这一项也可归入第一段，按实际情况写明） |
| 除斥期间届满 | 撤销权、解除权等形成权在法定或约定期间内未行使而消灭；它消灭的是权利本身，**不是诉讼时效** |
| 保证期间届满 | 债权人未在保证期间内依法向保证人主张权利，保证责任消灭；保证期间与保证债务的诉讼时效是两套期间，分别计算 |
| 其他权利存续期间届满 | 法律规定权利须在一定期间内行使、期满即消灭的情形 |

注意：部分消灭的，计算剩余部分；解除不是简单消灭，而是转换成新的请求权，要回到 `01-search-order.md` 重新排查。

期间问题要先定性：是除斥期间、保证期间，还是诉讼时效。前两者写在本段；只有诉讼时效写在第三段。

## 第三段：请求权是否可以行使

请求权存在且未消灭，但对方可能享有拒绝履行的权利。本段**只列抗辩权**（权利阻止的抗辩）；除斥期间、保证期间届满写入第二段。

| 类型 | 要点 |
| --- | --- |
| 诉讼时效 | 时效届满后义务人可拒绝履行；**须由当事人主张，法院不主动适用**；注意起算、中止、中断 |
| 同时履行抗辩权 | 双务合同、互负债务、没有先后履行顺序 |
| 先履行抗辩权 | 有先后顺序，先履行一方未履行或履行不符合约定 |
| 不安抗辩权 | 先履行一方有确切证据证明对方丧失或可能丧失履行能力 |
| 一般保证人的先诉抗辩权 | 主债务未经审判或仲裁、未就主债务人财产依法强制执行仍不能履行之前 |
| 履行期限未届至 | 请求提前履行 |

抗辩权与前两段事由的区别：前两段的事由属于权利是否产生、是否消灭的法律适用问题，不以当事人援引抗辩权为要件；抗辩权须由义务人主张才发生效力，诉讼时效最典型，法院不主动适用。但不要把前两段写成"一律依职权审查"：法院对哪些事由会主动审查、需要当事人提出到什么程度，以数据层返回的规则和律师判断为准。输出时把"对方是否已主张"单列一栏。

**履行期限与其他要件的关系**：履行期限未届至，一律在第三段处理。期限是否届至同时是另一请求的要件或影响另一项判断的（例如迟延责任、诉讼时效的起算、出资加速到期），在那里只写"见第三段"并说明联动关系，不重复检验。

**再抗辩**：对方提出抗辩或抗辩权后，请求权人可能提出再抗辩（例如对诉讼时效抗辩主张中断、中止，对撤销权主张除斥期间已过）。再抗辩写在它所针对的那一项抗辩之下，由请求权人举证；依据的用途标"再抗辩"。

## 三段之后：数额

请求权成立，不等于诉请的数额成立。三段式检验之后，逐项检查数额：

1. **计算要素**：基数、标准（比例、利率）、起止日、天数，各自的依据（合同条款、法律规定或事实）。每一项都可能成为争点，分别写明证据。
2. **部分成立**：免责事由、部分清偿、部分消灭只影响一部分数额的，写出扣减后的计算方式，不把整个请求写成"成立"或"不成立"。
3. **数额抗辩**：对方可能请求调整违约金（过高请求减少，过低请求增加）、主张损失赔偿受可预见性等规则限制、主张与有过失或减损规则等。这类主张须由当事人提出，不是第二段的消灭事由，也不是第三段的抗辩权，单列在这里；规则和举证分配由数据层返回。只写出法院可能考量的因素，不替法院定数额。
4. **利息与其他附随请求**：起算点、标准、计算至何时，同样写明依据。

材料中的金额相互矛盾的（见 SKILL.md 工作流第 1 步），先列为缺口，再按各种可能分别计算。

## 对方可能的反请求

代理一方时，同时写出对方可能提出的反请求或主动抵销（立场中立时不用本节，对方可能提出的请求列在第一部分，见 06 的"立场"；RR 中这一行写"立场中立，见第一部分"）：例如对方以我方违约为由请求违约金、赔偿损失，或以其债权抵销。只列可能性、依据方向和需要预判的证据，不作完整检验；律师需要时，以对方为请求权人另作完整分析。

## 输出

```text
候选：[规范名称]
第一段 已产生：成立 / 不成立 / 待证（要件清单见涵摄表）
  权利未发生的抗辩：[有 / 无 / 可能]，内容……
第二段 未消灭：成立 / 部分消灭（剩余……）/ 已消灭
  权利消灭的抗辩：……
第三段 可行使：成立 / 受阻
  抗辩权：[类型]，对方是否已主张：诉讼中已主张 / 仅在诉讼外表示过 / 未主张 / 未知
数额：计算要素……；部分成立的扣减……；数额抗辩……
对方可能的反请求：……
结论：在所列事实与依据下，本请求权【可被证明 / 不能被证明 / 取决于以下待证事实】
```
