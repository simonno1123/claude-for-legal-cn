# 05 执行程序中的运用

执行程序中，实体争议的核心往往不是"甲能不能向乙请求"，而是**两个权利谁优先**：申请执行人的债权，与案外人或被执行人主张的权利，哪一个应当让步。请求权基础方法在这里要调整为**对抗关系的审查**。

执行争议中，请求目标不是"谁得向谁请求给付"的（例如排除强制执行、许可执行、对分配方案的异议），在输出第二部分写"执行争议，按 05 第×节审查"，不逐一走 01 的七类检索；其中涉及的实体权利（例如案外人的所有权、债权是否真实）仍按三段式检验，写在第三部分。

## 一、案外人执行异议之诉

**审查问题**：案外人对执行标的是否享有**足以排除强制执行的民事权益**。

1. **案外人主张什么权利**：所有权、其他物权、物权期待权、租赁权、债权、股权等。写成"案外人主张对 [标的] 享有 [权利]"。
2. **该权利是否成立**：按本技能的三段式检验，检验案外人的权利是否已产生、未消灭。
3. **该权利能否对抗申请执行人的债权**：
   - 权利性质：物权原则上优先于普通债权；普通债权一般不能排除执行；物权期待权在满足特定条件时可以排除执行。
   - 时间点：权利的取得或要件的满足，是否在查封、扣押、冻结之前。
   - 特别规则：不动产买受人、商品房消费者、被执行人名下但实际属于他人的财产（借名登记、代持、挂靠车辆等）的排除执行条件，由数据层返回相应的司法解释规定（检索提示：最高人民法院关于执行异议和复议案件的规定中关于不动产买受人和商品房消费者的条款，以及相关的批复和会议纪要）。
4. **申请执行人一方的反驳**：申请执行人对执行标的是否另有优先权利（抵押权等），以及案外人的权利是否因虚假交易、恶意串通而不应保护。

**举证**：案外人对其享有足以排除执行的权益负举证责任；申请执行人对其反驳事由负举证责任。

## 二、申请执行人执行异议之诉（许可执行之诉）

执行法院支持了案外人的异议、中止执行后，申请执行人请求继续执行。审查结构同上，方向相反：申请执行人主张案外人的权益**不足以**排除执行，要件和举证责任按上面拆解。

## 三、变更、追加被执行人

**审查问题**：第三人是否应当对生效法律文书确定的债务承担责任，因而被变更或追加为被执行人。

1. **追加的事由属于哪一类**：例如股东未缴纳或未足额缴纳出资、抽逃出资、未履行出资义务即转让股权、一人公司股东不能证明公司财产独立于自己的财产、法人分立或合并、个人独资企业或合伙企业的投资人或合伙人等。每一类对应一个规范，由数据层返回（检索提示：最高人民法院关于民事执行中变更、追加当事人若干问题的规定；新《公司法》关于出资责任与加速到期的规定）。
2. **对该事由作三段式检验**：要件是否齐备（例如出资义务是否已到期，或是否符合加速到期的条件）；是否已经消灭（已补足出资）；是否有抗辩（例如责任范围以未出资本息为限）。
3. **程序路径**：追加申请、执行异议、执行异议之诉之间的关系，由律师判断并依数据层返回的规则确定。

## 四、参与分配争议（分配方案异议之诉）

被执行人财产不足以清偿全部债权、多个债权人参与分配时，争议的是**某一债权能否参与分配、按什么顺位、分多少**，而不是能否排除强制执行。**不适用"足以排除强制执行的民事权益"的框架。**

审查要点：
1. 参与分配的主体与时间条件是否满足（是否取得执行依据、是否在规定时间内申请等，规则由数据层返回）。
2. 被异议的债权是否真实存在、数额是否准确：按本技能的三段式检验对该债权作检验，重点核查虚构债权、恶意串通。
3. 清偿顺位：优先受偿权（担保物权、建设工程价款优先受偿权等）、普通债权，以及执行费用、共益费用的处理。
4. 程序路径：对分配方案的书面异议、反对意见、分配方案异议之诉之间的关系，由律师依数据层返回的规则判断。

## 五、实现债权的请求权

执行不能时，可以考虑向第三人主张，从而间接实现债权。按本技能的完整流程分析：

- 代位权：债务人怠于行使其到期债权或从权利，影响债权实现。
- 撤销权：债务人无偿处分财产，或以明显不合理的价格交易且相对人知道或应当知道，影响债权实现。
- 股东、实际控制人等的责任：出资责任、人格否认、清算责任。
- 保证人、担保物的实现。

## 六、财产线索的归类

执行中常见的情形是没有对抗关系争议，问题在于从哪里实现债权。此时把调查得到的每一条财产线索（银行流水、交易记录、登记信息等）归入下表，再对选定的路径按本技能的流程分析：

| 线索类型 | 可能的路径 | 通常需要补充的证据 |
| --- | --- | --- |
| 被执行人名下的财产 | 申请法院直接采取执行措施 | 财产的具体信息与权属 |
| 被执行人对第三人的到期债权 | 申请法院对到期债权采取执行措施，或另行提起代位权诉讼（见第五节） | 交易对手、债权数额、是否到期、第三人是否有异议 |
| 无偿处分、明显不合理价格的交易 | 债权人撤销权（注意除斥期间，属第二段） | 交易时间、对价、相对人是否知情 |
| 登记在他人名下、实际属于被执行人 | 申请执行该财产；他人异议时进入第一、二节的审查 | 出资、实际控制、使用的证据 |
| 股东出资、公司财产混同等 | 变更、追加被执行人（第三节）或另诉 | 出资情况、财务资料 |
| 被执行人有能力履行而隐匿、转移财产 | 拒不执行判决、裁定的刑事追究——**超出本技能范围**，标明并转向专门方法 | — |
| 财产处置障碍（证照不全、权属不清等） | 执行程序问题——**超出本技能范围**，作为程序事项交律师处理 | — |

一条线索可能对应多条路径的，全部列出，由律师选择。破产程序（申请债务人破产、执行转破产）可以作为程序选项列出，但其中的分析**超出本技能范围**。
