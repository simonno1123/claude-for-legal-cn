# 中国民商事诉讼/仲裁高压测试用例

| Case 编号 | 场景标签 | 输入测试数据点 | 预期输出 |
|---|---|---|---|
| Case 1 | 或审或仲 | 股权回购协议约定“可向原告所在地法院起诉，亦可向深圳仲裁委员会申请仲裁”。 | Critical：识别争议解决条款不确定，提示仲裁协议可能无效，需重新判断法院管辖和保全路径。 |
| Case 2 | 诉讼时效 | 货款 2021-03-01 到期，2024-04-01 才准备起诉；中间仅有 2023 年微信催款和对方“下月付”的回复。 | High：按三年普通诉讼时效审查，识别微信催款/承诺可能构成时效中断但需验证真实性、主体和完整上下文。 |
| Case 3 | 调查令 | 原告只有对方支付宝昵称和交易号，无法取得实名身份和收款账户。 | Pass：提示申请律师调查令/法院调查取证，列明拟调查平台、调查事项、无法自行取得理由和证明目的。 |
| Case 4 | 诉前财产保全 | 被告拖欠 800 万货款，正在转让名下房产和股权；原告尚未起诉。 | Critical：建议评估诉前财产保全，列明担保、财产线索、起诉期限、错误保全赔偿风险。 |
| Case 5 | 电子证据三性 | 原告提交微信聊天截图、导出的 Excel 对账单和录音，均无原始载体说明。 | High：按真实性、合法性、关联性逐项质证，提示补充原始手机、微信号实名、导出过程、公证/可信时间戳和录音取得合法性。 |
| Case 6 | 证人出庭 | 关键事实仅有离职员工愿意作证，没有书面证据。 | Warning：提示证人证言证明力有限，需申请证人出庭、说明证明事项和身份关系，并用书证/电子数据补强。 |
| Case 7 | 商业秘密证据提交 | 原告拟提交源代码、客户名单和报价模型证明被告侵权。 | Critical：不得承诺证据特权；应提示不公开审理、限制阅卷、证据脱敏、密封提交和商业秘密保护申请。 |
| Case 8 | 执行唯一住房抗辩 | 银行申请执行债务人唯一住房，债务人以“唯一住房”抗辩。 | Pass：提示唯一住房并非绝对不得执行，需审查基本居住保障、替代安置/租金补贴、执行异议和复议路径。 |
| Case 9 | 仲裁保全衔接 | 合同约定 CIETAC 仲裁，申请人希望冻结被申请人银行账户。 | Pass：提示通过仲裁机构转递法院保全或按规则申请，审查仲裁协议、保全法院、担保和紧急性。 |
| Case 10 | 协助执行通知 | 公司收到法院协助冻结员工工资账户/提供员工信息通知，但文书扫描件来源不明。 | Critical：先核验法院文书真伪、案号、公章、联系方式和协助范围；涉及个人信息时按最小必要披露并留存响应记录。 |

## 执行类情境（E 系列，全部虚构）

供 `enforcement-review` 人工回归使用。

| 编号 | 输入 | 应有表现 |
| --- | --- | --- |
| E1 | 金钱给付执行，曾终本后恢复，卷内两个执行案号 | D04 分别登记两个案号及终本、恢复文书和日期；终本状态不当然视为现状 |
| E2 | 卷内某查封裁定**载明具体到期日**，无续行文书 | 第六节照录到期日及出处，标 `[律师复核]`；不写"应续封" |
| E2b | 卷内某查封裁定**只载明期限长度**，没有具体到期日，也没有上游已复核的计算 | 不推算到期日；把裁定日期等起算相关日期与已核对的期间条文并列，标"未计算——`[律师复核]`" |
| E3 | 卷内无限制消费、失信记录 | 第六节列出两类措施及法定前提，逐项对照；不排先后 |
| E4 | 卷内有第三人对同一财产提出的异议 | 第三、四节和第六、九节相关事项都照录该异议；漏列即阻断 |
| E5 | 卷内有公司股东出资未缴足的线索 | 第八节列出可能涉及的法定情形和所缺材料；不写"可以追加" |
| E6 | 拟列执行异议途径，异议期间起算日在卷内矛盾 | 期限不推算，列为信息缺口，该事项阻断 |
| E7 | 候选中出现"建议先申请调查令"或"成功可能性较高" | 该事项阻断 |
| E8 | 所引规范在时效包中为"部分核对" | 标"可能相关、未经核对"，相关事项阻断 |
| E9 | 执行依据为扫描件，金额经人工目视读取 | 注明"人工目视"，金额标 `[律师复核]` |
| E10 | 卷内同时有参与分配程序 | D08 登记；第六至九节相关事项照录 |
| E11 | 依据目录中有某措施的已核对规范，案件时效包未收入 | 依据核查请求中列出该规范，注明"时效包未收入，请律师决定是否补入"；相关事项仍按未经核对处理 |
| E12 | 卷宗中混有一份当事人和案号都与本案不同、也不涉及本案被执行人、标的、财产或程序的裁定 | 登记为"疑似他案材料"，写明不一致之处，暂不作为本案事实依据，待律师确认 |
| E12b | 卷宗中有一份当事人和案号都与本案不同、但涉及本案已查封同一财产权属的裁定 | 不作为他案材料剔除；按 D08 交叉程序登记，并在相关事项中照录；漏列的，该事项阻断 |
| E13 | 首次申请执行日期只有律师口头陈述，卷内没有任何文书记载该日期 | 登记为"陈述（无文书）"，注明陈述人身份和日期；申请执行期间等依赖该日期的事项按起算日期缺失处理并阻断 |
| E14 | 卷宗附有事先整理的摘要；完整登记表中另有一组摘要未提及的材料，其标题显示涉及案外人 | 按登记表逐组登记；该组登记为"未审阅"，写明数量和标题，列入信息缺口；其标题显示可能涉及交叉程序的，在 D08 中登记为"可能的交叉程序（未审阅）" |
| E15 | 某执行程序节点只见于团队交接清单 | 登记为"工作记录（第二手）"，注明形成人和日期；不作为有文书证明的事实；依赖该节点日期的期限事项按起算日期缺失处理并阻断 |
| E16 | 律师只提供了部分材料，没有完整清单 | 注明"未见完整材料清单"，列入信息缺口 |

## 请求权基础方法接入情境（S43–S45，全部虚构）

| 编号 | 输入 | 应有表现 |
| --- | --- | --- |
| S43 | 买卖或借贷类请求，时效包只核对了部分规范 | 第 3A 步检索顺序逐类给出结论；三段式各段写明待证事实和抗辩；未核对的规范标"可能相关、未经核对"，不因副本"部分核验可引用原文"而引用 |
| S44 | 同一请求有两个以上候选请求权基础 | 全部列出并说明关系，不择一 |
| S45 | 副本要件表的"状态"栏可写"可证明" | `claim-chart` 输出不出现"可证明"等证明结论，不作三性认定 |
| S46 | 同一给付有三个以上已核对依据的候选 | 每个候选三段齐全；相同部分写明引用哪个候选的哪一段 |
| S47 | 一方只履行了部分义务，对方以未履行完毕为由拒绝全部对待给付 | 已履行部分和未履行部分分别检验抗辩，不笼统写成可以全部拒绝 |
| S48 | 请求返还原物，同时请求损害赔偿 | 返还原物候选写明要件不含过错和损害；与损害赔偿候选分开检验 |
