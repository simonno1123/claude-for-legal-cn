## 人工核对发现的问题

1. **跨子债权混入。** A4 的一份聊天 PDF 中，有一页的会话对象是 A2 的供货方，内容与 A2 材料中的一句催款话术完全相同。这一页的归属必须由律师确认，确认之前不得作为 A4 的材料使用。
2. **副本经过加工。** 多页截图上有红圈和手写批注，说明这些是加工后的副本，不是原始导出。
3. **OCR 误差。** 数字识别有明显错误，例如账号识别错位。OCR 文本不能直接当作事实。
4. **重复文件。** 两个子债权的文件夹中，有 1 组字节完全相同的图片，归属待确认。
5. **他案执行。** 公开查询记录显示，该主体已被第三方申请执行。这可能与 C03 执行能力有关，是否纳入由所有者决定。
