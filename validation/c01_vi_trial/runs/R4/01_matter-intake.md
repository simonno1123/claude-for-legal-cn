情形 A（10,000 元抵充利息，本金不减）：

- 到期应付本息：195,000 + 11,700 = 206,700.00 元

- 逾期利息示例（截至 2026-11-23）：195,000 × 6% × 267 / 365 = 11,700 × 267 / 365 = 3,123,900 / 365 = 8,558.63 元
- 复算：365 × 8,558.63 ≈ 3,123,899.95，与 3,123,900 相符

情形 B（10,000 元于 2025-09-01 抵充本金）：
- 第一段利息：195,000 × 6% × 184 / 365 = 11,700 × 184 / 365 = 2,152,800 / 365 = 5,898.08 元

- 第二段利息：185,000 × 6% × 181 / 365 = 11,100 × 181 / 365 = 2,009,100 / 365 = 5,504.38 元

- 逾期利息示例（截至 2026-11-23）：185,000 × 6% × 267 / 365 = 11,100 × 267 / 365 = 2,963,700 / 365 = 8,119.73 元
- 复算：365 × 8,119.73 ≈ 2,963,701.45，误差为四舍五入所致，相符

到期时两情形差额：196,700.00 − 196,402.47 = 297.53 元；复算：10,000 × 6% × 181 / 365 = 600 × 181 / 365 = 108,600 / 365 = 297.53 元，相符。
