## 5. 仍未建立的能力

- 调用侧数组可能并发变化，有限复制可能组合不同时间的元素观察；不证明输入曾在某一时刻包含一致记录。调用者在 API 之外的分配、总内存、宿主时间及极端异常仍 LIMITED。
- 数组长度检查不是实际 reader 的39+1超量检测、完整流结束或 EOF；7371bytes只是189×39的提议保守上界，本候选没有批次预算实施。
- 没有来源认证、worker/channel/SHA绑定、真实运行四态证据、顺序/唯一性、正常提交与首次stop的原子线性化、输出封锁、计时/停止或资源收束。
- 没有可信装载、M两次调用/副本修改/完整值比较、189项受控捕获、D-007准备、来源准入或集成；不通过语法候选绕过现有拒绝入口。

全部上游 LIMITED 保留。D-007保持 `UNBOUND / NOT_RUN`，真实 driver 正向 SHA 分支 `NOT COVERED`；120/5/5秒及39/7371仍为设计提议。DSP-004保持 `OPEN / HOLD`，B-01、B-02保持 `OPEN`。
