## 1. 第 ①步：专用运行时

- 位置：`C:\Program Files\DSP004Runtime`，其中 `Python312` 是运行时，`empty_pycache_prefix` 是空的字节码前缀目录。
- 访问控制：所有者是管理员组；SYSTEM 和管理员组完全控制；普通用户只能读取和执行；不继承上级目录的权限。
- 复制了 653 个文件。REV19 记录的 44 个 PE 文件、68 个导入时闭包文件，以及 REV20 记录的 2 个编码模块，SHA 全部相符。复制中没有缓存字节码。
- 如实记载：实际运行的 `setup_runtime.ps1` 是记录人较早的一版。它和记录人后来在本地改过的版本只差第 2 行注释（后来删掉了一段中文）和换行符，代码行完全相同。仓库提交的是实际运行的那一版。

## 2. 第 ②步：监督程序

- `supervisor_t0.ps1`（9346 字节，`54B735F2606344F12B80C82EF343836C3FABB6FF98680014ED1002CF3182DA47`），由 Windows PowerShell 5.1 运行。
