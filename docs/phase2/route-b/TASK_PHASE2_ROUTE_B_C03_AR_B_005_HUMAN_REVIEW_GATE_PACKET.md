## 一、角色

| 角色 | 担任者 | 职责 |
| --- | --- | --- |
| 生成者 | C03 能力层（Claude 运行） | 只生成候选输出，状态固定为"待人工复核，下游阻断" |
| 复核人 | 合格执业律师（治理代号 `REVIEWER-01`） | 按第三节的清单复核一份具体候选，作出 4 种处置之一 |
| 下游授权人 | 所有者（AR-B-010 逐项授权） | 决定一份已获 APPROVE 的候选能否进入下一步 |
| 记录人 | Claude | 只记录，不复核，也不授权 |

**取值 A（待所有者确认）：** 本项目目前只有一名执业律师，就是所有者。所以 `REVIEWER-01` 由所有者担任，下游授权人也是所有者。这满足"不得复核自己生成的内容"，因为候选由 C03 生成，不是所有者生成的。但这样一来，复核与授权由同一人担任，存在职责集中。可选的处理有两种：
- 接受这一集中，作为已知局限写明；
- 对重要的候选另设第二复核人，例如同所的其他执业律师。

## 二、资格与独立性（E-006 复核人独立性记录）

每一次复核前，以下各项须逐项为"是"，否则复核关口阻断：

1. 复核人是现在执业的律师，执业证有效（执业证信息只记在本机，不进入公开仓库）。
2. 复核人没有参与生成这份候选，也没有修改过它。
3. 复核人与本案不存在未经处理的利益冲突。本案代理律师复核本案候选，不视为冲突。
4. 复核人的角色和身份明确，不由 AI 或任何自动化程序代为复核。
5. 复核人知道这份候选的局限，也知道哪些用途被禁止。

资格或独立性发生变化时，以前的复核结论自动失效。

## 三、复核清单（封闭清单）

复核人逐项勾选，任何一项不能勾选为"通过"，处置只能是 REJECT、REQUEST CORRECTION 或 KEEP BLOCKED：

| # | 检查项 |
| --- | --- |
| C1 | 候选绑定的案件代号与版本正确，没有混入其他案件的材料 |
| C2 | 候选引用的每一项材料都有登记代号和 SHA-256，并且在证据矩阵中处于可用状态 |
| C3 | 候选中的每一条事实都标了出处；OCR 或提取文本没有被当作事实 |
| C4 | 候选引用的法律依据都在依据时效包中，并且在有效期内 |
| C5 | 候选没有给出法律结论、胜诉判断或对外的意见 |
| C6 | 候选没有提出、也没有暗示需要执行任何有法律后果的动作 |
| C7 | 候选中的冲突和局限都已列明，没有被隐藏 |
| C8 | 候选只包含完成目的所需的最少个人信息 |
| C9 | 候选的输入和输出 SHA-256 与复核包一致 |

## 四、复核包（packet contract）

每一份待复核的候选，复核包必须包含：
- 候选代号、版本、输出 SHA-256，以及生成时间；
- 案件代号，以及这份候选要服务的具体目的；
- 输入清单：每一项材料的代号和 SHA-256；
- 依据清单：依据时效包中对应的条目；
- 已知冲突、局限和禁止用途；
- 复核人代号，以及当次的独立性记录（第二节）；
- 复核清单的勾选结果（第三节）；
- 处置结果、理由和日期。

复核包缺少任何一项，或者复核过程中候选被修改，复核关口阻断，须重新出具复核包。

## 五、处置（只有以下 4 种，原文照用）

```text
REJECT
REQUEST CORRECTION
KEEP BLOCKED
APPROVE A SPECIFIC CANDIDATE FOR A SEPARATELY AUTHORIZED NEXT STEP
```

- APPROVE 只表示"可以另行申请下一步"，下游仍然阻断，要等 AR-B-010 的逐项授权。
- 处置只对这一份候选、这一个版本有效。候选一旦被取代或修改，处置就失效。
- 代码层面，这一点已由 V6 实现：处置只认上面 4 种原文，批准之后下游仍然阻断。

## 六、升级边界

以下事项复核人不能在复核关口中决定，必须升级到所有者本人另行决定，或者根本不在 C03 的范围内：
- 对外发送、提交、签署、付款、披露，或任何会产生法律后果的动作；
- 涉及委托人利益的重大取舍，例如是否接受和解、是否申请拍卖、是否移送公安；
- 对另一案件的材料作出判断；
- 改变复核规则本身。

## 七、留痕

- 复核记录（复核包、勾选结果、处置）保存在所有者本机的私有目录，按案件分别存放。
- 公开仓库只记录：候选代号、处置结果、日期、复核人代号，以及清单是否全部通过。

## 八、失败即关闭与撤回

- **失败即关闭的情形：** 复核人复核自己生成的内容；角色不清；资格缺失；复核包不完整；存在未解决的重大冲突。
- **撤回的情形：** 资格或独立性发生变化；复核包被修改；候选被取代；复核被撤销。

## 九、需要所有者确认

1. 取值 A：复核人与下游授权人由同一人担任，是接受这一集中，还是对重要候选另设第二复核人。
2. 第三节的 9 项清单是否完整。
3. 第六节的升级边界是否合适。
