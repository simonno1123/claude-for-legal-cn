## 一、程序经过

1. **一审。** 判决两名被告共同支付货款及利息。判决书本金有笔误，事后以补正裁定更正。
2. **二审。** 一名被告上诉，但未预交上诉费，按撤回上诉处理，一审判决随之生效。
3. **申请执行。** 申请执行后，申请人通过调查令取得两名被执行人多家银行的流水，并委托会计师事务所做资金收支专项审计。
4. **查封与处置。** 查封了一名被执行人名下的唯一一处不动产。该房产上已设有银行在先的最高额抵押，拍卖属于无益处置。
5. **执行和解。** 申请人与一名被执行人达成长期分期履行的执行和解，法院以和解为由终结执行。和解协议只有一名被执行人签署。
6. **恢复执行。** 被执行人第二期未按约履行，申请人申请恢复执行，法院已恢复强制执行。恢复执行后，被执行人又付了一笔现金。
7. **拒执罪。** 申请人以审计结论为依据，申请移送拒不执行判决、裁定罪。当地公安机关目前按统一口径暂不受理，没有进展。
8. **另一名被执行人。** 至今下落不明。

## 二、需要 C03 识别的执行难点

| 编号 | 难点 | 可观察的信号 |
| --- | --- | --- |
| P1 | 唯一财产上已有在先担保物权，拍卖属于无益处置 | 不动产登记中的抵押记载；最高额抵押合同；处置申请中承认存在优先权 |
| P2 | 查封与续贷相互牵制 | 担保银行续贷要求抵押物无其他权利负担，而本案查封恰恰构成负担 |
| P3 | 执行和解只约束部分被执行人 | 和解协议签署人少于被执行人；终结裁定却涉及全部被执行人 |
| P4 | 和解后不履行，需恢复执行 | 分期未按期支付；恢复执行申请；收款为现金，没有凭证 |
| P5 | 被执行人下落不明 | 多名被执行人中只找到一人 |
| P6 | 拒执罪的刑事路径受阻 | 审计显示，连续六个月以上期间的支出超过当地的拒执认定标准；公安按统一口径暂不受理 |
| P7 | 文书和数额口径不一 | 判决笔误后补正；工作稿中本金口径和日期前后不一致 |
| P8 | 材料来源复杂 | 原件、派生整理件和工作稿混在一起；同一材料多处重复存放；混入他案文件 |

## 三、所有者的实务判断（2026-11-07）

P2 不只是僵局，更是筹码。银行续贷要求抵押物无其他权利负担，被执行人要续贷就必须设法解除查封，查封由此成为促使其履行的谈判杠杆。

**要求 C03：** 遇到"在先担保加续贷需求"的组合时，C03 应当识别出其中可能存在的履行杠杆，并提示律师评估，而不能只给出"拍卖属于无益处置"的消极结论。是否利用这一杠杆、如何谈判，由律师决定。

## 四、C03 在各难点上的边界

| 难点 | C03 可以做的（候选输出，需人工复核） | C03 不得做的 |
| --- | --- | --- |
| P1、P2 | 标出在先担保与无益处置的风险；把续贷形成的杠杆作为待评估事项列出；整理需要向银行调取的材料清单 | 自行决定是否申请拍卖；与银行或被执行人联系 |
| P3 | 标出和解协议的签署范围与终结裁定的范围不一致 | 认定和解协议对未签署人的效力 |
| P4 | 列出恢复执行的条件和材料缺口，包括现金收款没有凭证 | 认定已付金额；对外提交恢复执行申请 |
| P5 | 列出查找下落的合法途径，供律师选择 | 自行检索或汇总个人行踪信息 |
| P6 | 把审计结论与适用标准并列，供律师判断 | 认定是否构成犯罪；向公安机关提交任何材料 |
| P7、P8 | 标出口径冲突、派生件和混入的材料 | 自行选定以哪个数额或哪份文书为准 |

## 五、作为验证样本的用法

- **场景化。** 以上 8 个难点可以转写为合成 Fixture，用于 C03 后续的场景验证，与现有的 15 个场景互补。现有场景偏重平台控制，这里补充的是执行业务本身。
- **对照。** 真实材料只留在所有者本机。合成 Fixture 只保留难点的结构，不带真实事实。
