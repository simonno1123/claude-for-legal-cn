## 0. 必须先说明的三条边界

1. **有些事实只能由所有者或项目提供，不能由记录人编造。** 交接 REV1 第 5 节写明：不能发明六侧来源、可信根、批准记录或已完成的独立审查，也不能把候选宣告为所有者已接受。记录人能做的是起草候选、编写和运行工具、整理证据、组织审查；接受与否由所有者决定。
2. **审查独立性。** 到目前为止，所有审查都来自与记录人同一个模型家族。正式验收至少需要一次不同来源的审查，例如项目已经在用的 Codex 或 Cursor，或者一位人工审查者。
3. **REV17 记下的拒绝、保留和不授权需要逐项改签。** 当时选择这些，是为了停在"资产墙"前。要完成验收，就必须越过资产墙，每一项都要由所有者重新决定。
