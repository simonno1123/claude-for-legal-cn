新增载体仅运行下表中七个封闭合成情景。它与已绑定 REV2 快照在同一内存程序集编译，复用内部纯截止分类及确认分帧方法，但进程启动、读取循环和停止处理属于新增测试实现，不是 REV2 的实际完整运行路径。确认标记是合成输出，不证明任何输入 SHA、来源或权限。

每个测试使用 5000 ms 的实际短时观察预算。将实际短时样本加 115000 ms 后传给 REV2 的 120000 ms 纯分类方法，只用于等价阈值分支检查；不代表实际运行了 REV2 的 120 秒合同，也不证明成熟硬时限。

| --- | --- | --- |
| S-01 | 输出合成确认标记和固定控制 JSON，exit 0 | 仅控制情景完整捕获，不建立业务结果或权限 |

## 输出、停止和判定

- 固定 pwsh 绝对路径、无 profile、非交互、隐藏窗口；清空继承环境，仅补必要路径/遥测关闭项。所有 child 程序均为载体内固定 .NET 写出/等待语句，没有业务文件读取或网络访问。
- stdout/stderr 并发正数读取，最大请求为剩余正文预算加一个检测字节；发生检测后不继续无限读取。公开结果只包含固定原因、计数和最小事件状态，不输出原始失败流、异常 Message 或堆栈。
- 第一个保护性原因锁定后不再发布正常正文、不得恢复确认资格；只对本情景持有的子进程请求终止，分别记录请求、实际退出观察及读取任务结束状态。每情景停止后的退出等待与流等待各为最多 2000 ms 的设计参数；同步调用本身仍无可证明硬界限。
- 原异常及次级异常仅保留在本进程私有记录中；公开类型元数据不替代或声称跨进程保留原对象。
- 情景原因/结果形状的预期写在另一个固定入口文件中，不依据载体返回结果生成预期。任何失败必须保存实际记录，不用缺失项或未覆盖项补造 PASS。
- 新载体每个编译程序集只允许一次七情景批次，重复请求必须拒绝，不增加子进程。该本地门不是跨会话/跨进程的全局一次性权限服务。
