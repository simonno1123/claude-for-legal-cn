## 一、问题

现行细则要求每次只问一项。按此严格执行，一份 L1 成果（含 AR-B-010）约需 47 次问答：M 1、I 6、T 1、C1–C11 11、C5 期限状态约 4、R 2（重大冲突、处置）、Q1 5、提交 1、Q2 5、授权 1、Q3 10（对照复查五项加授权核对五项）。另有 W、停点查询，视情况而定。

实际执行中，记录人为减轻负担，曾多次把多项合成一个单选题，偏离了逐项作答的要求：AR-B-010 首次运行中的 Q3（TF-10），以及 CASE-E 两条授权链中的 Q1、Q2、Q3（见第五节）。负担过重导致不合规，这比问题多本身更值得解决。

## 二、修订内容：分组逐项勾选

在方式 c 下增加一种问法，称为"分组勾选"：

1. **一题多项、每项单独勾选。** 一道题列出同一记录、同一阶段的至多 4 项，每项是一个独立的勾选框，写出该项全文，**默认都不勾选**。复核人勾选一项，即是对该项的正面确认；这与 R3 §3.1 等效人工确认（a）"在打印件上逐项勾选"相当。
2. **未勾选即未确认（失败即关闭）。** 任何一项未勾选，或复核人在"其他"中填写了内容，都按"未确认／不通过"处理：记录人不得自行补勾，也不得推定为遗漏；须立即就该项**单独**再问一次（一题一项），并照原话转录两次答复。仍未确认的，按该记录的规则停止或登记停点。
3. **适用范围（只限确认类事项）。** 可以分组的只有以下各项：
   - I 的六项声明：分两题（1–4 项、5–6 项）；第 4 项"输入参与"有三个选项，仍单独成题。
   - C1–C11：分三题（C1–C4、C5–C8、C9–C11）。题干照录每项检查的全文和提示。
   - C5 的期限状态：每项期限写明"项目＋拟定状态＋依据"，每题至多 4 项；勾选即确认该项状态，未勾选的单独再问。
   - Q1、Q2、Q3 的五项对照复查：分两题（1–4 项、第 5 项）；Q3 的五项授权核对另分两题。
4. **不得分组的事项（仍一题一项、单选）。** 定级（T 的用途代号与 L1 正面确认）；实质修正的判定；W 的重核结论；停点相关性及是否已覆盖；R 的重大冲突；R 的处置；提交申请；授权决定；使用。凡是**判断、处置或决定**，一律不与任何确认项同题，也不跨记录、跨阶段合题（例如 Q2 与授权决定不得同题）。
5. **转录与记时不变。** 每题答复后立即转录；每份记录仍单独形成、单独记时（TF-06）；同一题内各项的答复时间相同，按该题提交时刻记录。
6. **题目写法。** 题干写明这是哪一份记录的哪几项；每项写全文，不用"同上""已知悉"之类的概括；涉及概念的（如有效截止、相关性），在项内写明判断标准（TF-08、TF-11）。

## 四、风险与对策

| 风险 | 对策 |
| --- | --- |
| 漏勾（L1 试运行中 C2–C4 曾漏点，当时须事后更正） | 第二节第 2 项：未勾选一律按未确认处理，**在形成该记录之前**单独补问，不再出现事后更正 |
| 一次勾选整组而未逐项阅读 | 每组至多 4 项，每项写全文；判断、处置类事项不分组；C6、C7 等实质判断项仍以复核人对原件的审阅为准，记录人不提示"建议通过" |
| 合题蔓延 | 第二节第 4 项列明不得分组的事项；记录人每次形成记录时在私有就绪包中注明所用问法（单题或分组） |

## 五、需要披露的既往偏离

CASE-E 的两条 AR-B-010 授权链中，Q1、Q2 各把五项对照复查合成一个单选题，Q3 把五项对照复查与五项授权核对合成一个单选题。这与 TF-10 的偏离相同，记录人当时没有说明。第二条授权链的使用前代码校验已通过、使用已登记，本修订不改变其效力；该偏离作为局限补记（CE-09）。是否需要补救，由所有者决定。
