## 一、为什么先试 Tesseract

- 复用评估（2026-08）当时在所评估的环境中没有发现任何识别引擎。
- 现状已经变化：所有者电脑上的 Claude 工作环境（Linux 虚拟机）里已有 Tesseract 4.1.1，但只有英文和方向检测两个语言包，没有中文。
- 只补一个中文语言包，就能检验现有引擎是否够用，不必另装框架。达不到标准的，再回到 PaddleOCR。

## 二、候选

| 项 | 内容 |
| --- | --- |
| 引擎 | Tesseract 4.1.1（已在环境中，不另装） |
| 语言包 | `chi_sim.traineddata`，取自 GitHub 上的 `tesseract-ocr/tessdata_fast` 主分支 |
| 取得方式 | 所有者本人在浏览器中下载，放入私有目录 `_tools/tessdata/`，记录 SHA-256。记录人所在的环境连不上 GitHub，不代为下载 |
| 加载方式 | 用 `--tessdata-dir` 指向该目录，不写入系统目录，不改系统设置 |
| 备选 | `tessdata_best` 中的同名文件（更大、更慢、通常更准），只在 fast 版结果为"有限"时另行评估 |

## 三、样本：只用虚构样本

由记录人在同一环境中生成，**不使用任何真实案件材料，也不使用真实个人信息**：

1. **字体：** 环境中已有的 Noto Serif CJK SC，以及同系列的无衬线字体（有就用）。
2. **样本类型**，每类 3 页，共 18 页：
   - 判决书段落：含法条引用，如"《中华人民共和国民法典》第五百七十七条"，以及按法院案号格式生成的虚构案号（年份、地区码、类型字和序号随机）；
   - 对账单表格：日期、品名、数量、单价、金额、合计，含千分位和小数；
   - 起诉状首部：虚构姓名、虚构身份证号格式字符串、地址、电话；
   - 收据或借条：大写金额（壹拾万元整）与小写金额并列；
   - 印章覆盖：用红色圆形和文字模拟印章，压在正文上；
   - 混排：中英文、全角与半角数字、标点混排。
3. **劣化版本**：每页再派生 5 个版本。
   - 低分辨率：150 dpi；
   - 旋转：±3°；
   - 模糊：轻度高斯模糊；
   - JPEG 压缩：质量 30；
   - 翻拍模拟：透视变形，加光照不均。
4. **标准答案：** 生成时同步保存逐行文本和字段清单（金额、日期、法条号、案号、证件号），作为评分依据。
5. 样本与标准答案存放在私有目录 `_tools/ocr_benchmark/`；生成脚本与结果汇总可以入仓库，样本图片不入仓库。

**不覆盖：** 手写体、真实印章、真实复杂版面。这些只能在另行授权的真实材料抽样中评估。

## 四、指标

| 指标 | 定义 |
| --- | --- |
| 字符错误率（CER） | 编辑距离除以标准答案字符数，分"清晰"和"劣化"两组统计 |
| 关键字段完全匹配率 | 金额、日期、法条号、案号、证件号逐字段比对，只计完全一致 |
| 数字错误率 | 只统计数字和小数点的错误，单独列出 |
| 表格单元格匹配率 | 对账单类样本的单元格级别比对 |
| 失败页数 | 无输出或输出明显错乱的页 |
| 每页耗时 | CPU 运行时间 |
| 置信度可用性 | 低置信度区域与实际错误位置的重合程度（以 TSV 输出中的置信度计算） |

## 五、判定标准

| 结论 | 条件 |
| --- | --- |
| **通过** | 清晰组 CER ≤ 3%，劣化组 CER ≤ 10%；清晰组关键字段完全匹配率 ≥ 98%；失败页数为 0 |
| **有限** | 未达"通过"，但清晰组 CER ≤ 8%，且关键字段错误都能被低置信度标记覆盖。只能作为"识别候选"使用，关键字段一律人工核对 |
| **不通过** | 达不到"有限"的。转回 PaddleOCR 受控基准测试设计 |
| **立即停止** | 出现任何网络外联、样本以外的文件读取，或写入了约定目录以外的位置 |

无论结论如何，识别结果都只是候选：按 C01-V 包 V3 注明"识别（Tesseract 4.1.1 / chi_sim fast）"，关键日期、金额、签章标 `[律师复核]`。

## 六、控制措施

1. **离线：** 运行环境不连外网（现状已是如此），运行前后各检查一次。
2. **隔离：** 只读样本目录，只写结果目录；临时文件放在环境的临时目录，运行结束后清点。
3. **可追溯：** 每次运行都记录引擎版本、语言包 SHA-256、命令参数、样本清单 SHA、开始和结束时间；原始输出（文本与 TSV）完整保留，不修改。
4. **定位信息：** TSV 中的页、行、坐标随结果一并保存，供人工比对原图。
5. **一次性：** 一次运行一组参数；改参数要重新记录，不覆盖旧结果。
