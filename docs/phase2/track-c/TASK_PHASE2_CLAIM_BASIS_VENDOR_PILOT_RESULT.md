### 3.3 其他观察

1. 三次运行都把依据时效包本身的问题（核对人为 Claude、未交所有者确认、逐行"适用时点"缺失等）列入待复核。这是规则字典要求的提示，不是错误；包按交接本就不另行交所有者确认。
2. R3 指出技能引用的 `references/test-cases-cn.md` 不在工作目录中。这是运行隔离所致，不是技能问题。
3. R3 的复核记录表"复核状态"一栏写"未填写"，没有沿用其他运行的默认标签 `candidate`，并另行注明全部内容为 `candidate`。两种写法都没有自行填写复核结论，但写法不一致。
4. 没有出现预测裁判结果、选定请求权基础或代替律师作适用判断的情况。
