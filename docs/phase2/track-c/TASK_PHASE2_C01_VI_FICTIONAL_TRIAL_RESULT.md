## 三、发现的问题（供所有者决定是否立项）

1. **转述单一出处"载明"的金额，未被当作"使用金额"（E6）。** R1 撰稿把"借条载明 200,000 元"当作对书证内容的转述，只按一般复核门处理。撰稿第 6A 步说的是"命题所用金额"，没有写明转述某一出处所载金额也算在内。可以考虑写明：凡命题中出现核对表里仍未解释的金额，不论是作为事实认定，还是作为转述某一出处所载内容，都输出金额口径阻断。
2. **"没有差异"一节的输出格式没有被遵守（E10）。** 技能里这句要求只写在输出格式的引言中（"没有差异的，写'未发现金额口径差异'……"）。运行者看到表头后，改为逐行标注。可以考虑改为两点：
   - 在第 5 步的子项中明确写出这一输出；
   - 在表格之前固定一行"结论"。
3. **核对表混入了"计算情形"（R1、R4 都有）。** 核对表本来只记**不同出处之间**的金额差异；运行者把抵充顺序、计息基数不同所得的推算结果也写进同一张表，并在"差额"栏填了数字。R1 中这部分放在表前的复算段落里，问题不大；R4 则直接作为表格行。可以考虑明确两点：
   - 推算结果放在复算段落，不进核对表；
   - 或者在表中另设"推算"类型，并且不填"差额"栏。
4. **试跑设置带来的现象，不是技能问题。** R3 的虚构复核记录日期是 2026-11-22，而所复核的收案输出是 2026-11-23 生成的。撰稿技能据此把该命题判为"需补核"，没有判为"可进入律师复核"。这说明复核门对版本和日期的检查有效。按设计 E8，这一结果仍然符合，因为金额口径阻断已经解除，一般复核门照常检查。
5. **值得注意的正面表现：**
   - R3 撰稿指出，"5,000 元系出借人预扣"是原告的自认，又没有书证支持，在复核点中提示律师决定是否作此陈述；
   - R1、R2 都把律师函、起诉状草稿中"至今未清偿"等表述，标为与还款对账单矛盾的我方不利材料。
