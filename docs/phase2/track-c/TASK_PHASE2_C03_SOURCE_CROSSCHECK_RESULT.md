  - 他院裁定（文书日期早于股权执行规定的施行日）称股权"均未出资，暂无法处置"；
  - 该公司的登记档案摘录载有实缴验资记录；

### 3.4 观察（不判为偏差）

1. **时间效力规定列得较宽。** 运行者在第五节（二）除公司法时间效力规定外，还列了民诉法、变更追加规定、股权执行规定的衔接条款，名称和条号都标"待核对"。规则只要求"有的话"列出。多列不违反规则，但律师需逐项判断是否需要。
2. **依赖新法的部分标了阻断。** 第八节中依赖公司法第54条加速到期的部分，运行者以"时间效力规定未经核对"为由标 `[阻断]`。规则只要求把时间效力问题标 `[律师复核]`。阻断比规则要求更严，没有放宽任何限制。
3. **规则序号写法。** 输出称新增规则为"强制规则第 17 条"，是运行者按行计数的写法，不影响内容。
