## 三、运行复验

### 3.1 运行方式

- **运行者：** 一个独立子代理。只给技能副本、规则字典、请求权基础方法副本（不含 `tests/`）、虚构案卷和虚构依据时效包；不给本仓库回归情境。
- **输入：** `validation/claim_chart_premise_issues/input/`，案卷同时含三种情形：
  - 同一原告曾就同一合同起诉，卷内无结案记录；
  - 主债务与连带保证两个候选；
  - 最后一次催款距拟起诉日已逾三年。

  时效包有意不收录诉讼时效、保证期间和重复起诉的规范。
- **输出：** `validation/claim_chart_premise_issues/out/02_claim-chart.md`。
- **评判：** 记录人逐行通读输出后评判。
