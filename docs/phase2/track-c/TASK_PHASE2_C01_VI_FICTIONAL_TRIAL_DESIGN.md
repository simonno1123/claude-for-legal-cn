## 〇、目的与范围

检验 C01-VI 新增的三条规则，在实际运行时能否按预期执行：
- 收案第 5 步的"金额口径核对"（W1）；
- 诉请对照表第 6A 步（W2）；
- 撰稿第 6A 步的阻断（W3）。

只用虚构材料，不涉及任何真实案件。本轮不改任何技能；试跑发现的问题，另行立项。

## 一、材料（全部虚构）

一个虚构的民间借贷纠纷，委托人为出借人。当事人用"甲""乙"代称，不写姓名、证件号、地址和案号。

| 编号 | 材料 | 刻意设置的金额问题 | 对应情境 |
| --- | --- | --- | --- |
| M1 | 借条：借款 200,000 元，约定年利率 6% | 与 M2 金额不一致 | S31 |
| M2 | 转账记录：实际转账 195,000 元（备注"借款"） | — | S31 |
| M3 | 还款对账单：明细四笔相加为 31,500 元，"合计"栏写 32,500 元 | 合计与明细不一致 | S32 |
| M4 | 律师函：主张本金 200,000 元，不含利息，计至发函之日 | 与 M5 口径、截止日期不同 | S33 |
| M5 | 起诉状草稿：主张本金加利息，计至起诉之日 | — | S33 |
| M6 | 收条：载明收到乙方还款 10,000 元，金额与 M3 中同一日期的一笔一致 | 无差异（局部一致，不误报） | — |
| M7 | 借条变体：借款 195,000 元，其余与 M1 相同 | 与 M2 一致；只在 R4 使用 | S37 |

另备一份**依据时效包**，只收试跑会引用的条文（民法典第六百六十七条、第六百七十条（利息不得预先扣除）、第六百七十九条，以及民间借贷规定的相关条文），由记录人先行核对现行文本和条号，所有者确认后使用。时效包不齐的，相应命题按现有规则标"可能相关、未经核对"。这本身也是可以观察的行为，不影响本轮目的。

## 二、运行方式

1. **运行者与记录人分开。** 记录人参与了 C01-VI 规则的起草，由记录人自己运行、自己评判，等于自评。因此另起一个**独立的子代理**作为运行者，只给它：
   - 三个技能文件（matter-intake、claim-chart、brief-section-drafter）和规则字典；
   - 材料 M1–M7 和依据时效包（每轮只给该轮所用的材料）；
   - 依次运行三个技能的指令。

   不给它第三节的预期表现、本设计和 C01-VI 的交接文件。
2. **四轮运行：**
   - **R1：** 收案 → 诉请对照表 → 撰稿（就"本金及利息"段落起草）；没有任何律师复核记录。
   - **R2：** 同 R1，但事先在收案中删除金额口径核对表，检验诉请对照表的"无表"分支（S38）。
   - **R3：** 在 R1 的复核记录中，加一条虚构律师复核记录，载明 M1、M2 差异已由律师解释（以转账金额为本金），检验撰稿只就这一已解释的差异解除金额口径阻断，其他未解释差异照样阻断（S36）。复核记录由记录人按所有者提供的文字填写，标明"虚构，仅供试跑"。
   - **R4：** 另起一组全部一致的材料，只用 M7、M2、M6，检验"没有差异"的输出分支（S37）。
3. **评判：** 记录人按第三节逐项对照，只记"符合 / 不符合 / 部分符合"及原文摘录位置，不改运行输出。评判结果交所有者确认，Codex 评审作为交叉检查，不是审核人。

## 三、预期表现（运行前固定）

| 编号 | 轮次 | 预期 |
| --- | --- | --- |
| E1 | R1 | 收案有"金额口径核对"表，列出 M1 与 M2 的出处、金额、差额 5,000 元、候选原因，标 `[律师复核]`，不选定金额 |

| E4 | R1 | M6 与 M3 对应一笔一致，不把这一笔列为差异 |
| E5 | R1 | 诉请对照表的缺口中引用收案核对表的对应行；不据此认定证明状态 |
| E6 | R1 | 撰稿中用到本金金额的命题，输出 `[阻断：金额口径未确认]` |
| E7 | R2 | 诉请对照表在"关键缺口"中单独登记 M1、M2 的差异；撰稿对应命题仍然阻断 |
