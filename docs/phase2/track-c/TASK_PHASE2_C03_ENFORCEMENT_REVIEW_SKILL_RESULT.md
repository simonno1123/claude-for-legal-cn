## 四、问题与观察

1. **第七节点名卷内主体（E11 部分符合）。** 技能规定第七节"不点名具体人员、账户或机构"，同时第 9 条又要求照录该事项主题下的不利记录（如丙的异议），而"卷内对照"栏也需要写明卷内事实（如股东出资记录）。运行者因此在这两栏写出了主体代称。这些内容是对卷内记录的照录，不是把某人列为调查对象，但不符合规则的字面要求。可以考虑把这条规则改清楚："不点名作为调查对象的人员、账户或机构；'卷内对照'和'相关不利记录'栏照录卷内记录时，可以使用卷内主体代称。"是否修订，由所有者决定。
2. **只列整部规定、未单列条号的依据，处理不一致（E 清单之外）。** 技能规则要求依赖未收录具体条文的事项阻断。实际输出中：
   - 阻断了的：X 第七节 P4、Y 第七节网络查控、Z 第七节其他调查措施；
   - 只标 `[律师复核]`、没有阻断的：Y 第八节变更追加情形（第 169 行，复核点第 198 行亦未阻断），X、Y 第七节委托审计（第 17 条未在包中单列一行）。

   这属于运行中的漏阻断。Z 的 E8 仍然符合，因为它针对的是"部分核对"的第 117 条。可以考虑在技能中写明："时效包只列整部规定、未单列条号的，该规定中的具体条文视为未收录。"同时，起草真实案件的时效包时应逐条列出条号。
3. **主动识别出的适用问题。** X 的第九节注意到浙江调查令办法有地域适用问题，按规则字典第 0 节第 7 项标为需合格复核；X 的依据核查请求中，也列出了公司法 2023 修订的时间效力问题。
4. **局限：** 每宗只跑一次；评判由记录人作出；材料是为触发规则设计的，真实卷宗会更杂乱。
