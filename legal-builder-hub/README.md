# Legal Builder Hub (中国法律技能构建中心)

本模块提供中国法律技能质量审查、静态来源和配置检查、变更计划及 MCP 安全边界治理。它不直接提供实体法律意见，也不将安装、更新、回滚、禁用或卸载计划视为已经完成的物理操作。

静态审查和计划属于已有基线；实际技能生态操作属于 Phase 2，必须获得单独、明确的授权，并确认目标、来源、工具权限和变更范围。模块可发现、命令存在或审查通过均不自动授予执行权限。

## 核心能力

- 中国法律技能质量审查
- MCP 连接器占位配置检查
- 插件/技能安装、更新、回滚、禁用和卸载的计划及审查边界（不代表实际执行）
- 回归测试与乱码/JSON/frontmatter 验证
- AI/人工复核包生成的流程约束

## 推荐命令

- `/legal-builder-hub:cold-start-interview`
- `/legal-builder-hub:registry-browser`
- `/legal-builder-hub:skills-qa`
- `/legal-builder-hub:skill-installer`
- `/legal-builder-hub:skill-manager`

## 不做的事

- 不提供实体法律意见。
- 不绕过人工复核安装未审查技能。
- 不保存真实 API Key 或商业数据库凭证。
